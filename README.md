# Bond Valuation Engine Validation

Yield Curve 기반 채권 공정가치 평가 및 가격 검증 프로젝트

## 프로젝트 목적

공개 시장금리와 단순화된 평가모형을 이용해 채권의 기준가격을 계산하고,
금리변화에 따른 가격민감도와 평가결과 검증 과정을 구현했습니다.

## 주요 분석

- Yield Curve 구성
- 채권 현금흐름 생성
- Curve 기반 채권가격 계산
- Credit Spread 반영
- DV01 계산
- Effective Duration 계산
- 금리 Stress Test
- 기준가격과 평가가격 비교

## 사용 기술

Python
pandas
numpy
matplotlib
